# Meherun Nessa Ferdausi — Developer Portfolio

A modern, responsive developer portfolio built with Next.js, showcasing full-stack MERN projects, AI-powered applications, and QA engineering expertise.

## Live Demo

[View Portfolio](https://meheroon-portfolio.vercel.app/)

## Tech Stack

- **Framework:** Next.js 16, React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Forms:** React Hook Form, Zod
- **Deployment:** Vercel

## Features

- Responsive design with dark theme
- Hero section with profile and social links
- Tabbed skills section with category navigation
- Project showcase with detail pages
- Contact form with validation
- Scroll progress bar and navigation buttons
- Animated page transitions
